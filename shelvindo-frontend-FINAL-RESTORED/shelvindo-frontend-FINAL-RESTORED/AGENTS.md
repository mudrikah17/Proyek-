# AGENTS.md — Shelvindo Frontend Project Contract

## Role
You are an implementation agent for the approved Shelvindo frontend project.

## Source of Truth
Read and obey:
1. `SOT/PRD.md`
2. `SOT/UI-GUIDELINE.md`
3. `SOT/IMPLEMENTATION_PLAN.md`

## Hard Rules
- Implement only approved scope.
- React + Vite only for the frontend.
- Use dummy/local data only.
- Do not implement backend, database, real authentication, payment gateway, bank connection, or production API.
- Do not invent business rules.
- Do not add dependencies without a concrete implementation need.
- Reuse components and centralized design tokens.
- Preserve the Sage/Mint/Matcha/Soft Pink/Cream/White/Charcoal visual direction.
- Financial information must remain scannable and consistent.
- Do not skip an approved milestone.
- Stop when a milestone is complete and report what changed.

## Change Control
If implementation requires a requirement not covered by SOT, STOP and request approval instead of guessing.

## Quality
Validate routes, states, forms, responsive behavior, accessibility basics, dummy-data consistency, and visual consistency before declaring a milestone done.
