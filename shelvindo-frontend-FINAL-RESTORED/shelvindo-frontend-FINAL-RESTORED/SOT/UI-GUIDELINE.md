# UI-GUIDELINE — PT. Shelvindo Kurnia Cemerlang

## 1. Design Direction
Modern · Futuristic · Soft · Premium · Financial · Clean · Friendly.
Experience target: modern financial SaaS; visual identity remains original to Shelvindo.

## 2. Brand Palette
Sage, Mint, Matcha, Soft Pink, Cream, White, Charcoal.
Use centralized design tokens; avoid hardcoded brand colors across components.

## 3. Typography
Clean, readable hierarchy: Display → Page Title → Section → Card → Body → Caption.
Financial numbers must be highly scannable and formatted in Indonesian Rupiah.

## 4. Layout
Desktop-first app shell: Sidebar + Topbar + Main Content. Tablet uses collapsed sidebar; mobile uses compact navigation and card/list alternatives.

## 5. Dashboard
KPI cards: Sales, Expenses, Receivables, Payables. Supporting views: sales performance, cash position, recent transactions, due invoices, low stock.

## 6. Tables
Search, filter, sort, pagination, row actions, status badges, empty state. Responsive tables may become cards on narrow screens.

## 7. Status
Use icon + color + text. States include Paid, Unpaid, Partial, Overdue, Draft, Cancelled, Approved, Rejected.

## 8. Forms
Clear labels, required indicators, helper/error text, disabled/success states. Transaction forms are divided into logical sections.

## 9. Login
Minimal premium login with email, password visibility, Forgot Password, sign-in feedback. Forgot Password follows the PRD flow.

## 10. Invoice
Professional, printable structure with company header, invoice number, customer, items, totals, payment status, and due date.

## 11. Receivables & Payables
Financial cards and tables show total, counterparties, invoice counts, outstanding amount, due/overdue information.

## 12. Reports & Export
Report header, report type, period/date filter, summary cards, Export XLS, Export PDF, and detailed table.
Report types include monthly financial, sales, customer, receivables, supplier, payables, purchase, expenses, cash/bank, inventory.

## 13. Customer Summary
Show transaction count, total purchase value, paid amount, outstanding receivable, and last transaction.

## 14. Components
Button, Input, Select, DatePicker, SearchInput, Badge, Card, Modal, Drawer, Dropdown, Tabs, Table, Pagination, Tooltip, Toast, Alert, EmptyState, LoadingState, StatCard, ChartCard, DataTable, FormSection, PageHeader, Sidebar, Topbar.

## 15. Interaction
Primary/secondary/ghost/danger button hierarchy. Provide contextual feedback. Avoid excessive animation and decoration.

## 16. Accessibility
Keyboard navigation, visible focus, contrast, semantic controls, meaningful labels, associated errors, and non-color-only status communication.

## 17. Principles
Clarity first; financial data scannable; consistency over decoration; soft visual language; obvious actions; reusable components; comfortable density; one primary purpose per screen.
